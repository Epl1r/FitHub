# FitHub — мини-приложение Telegram

Полная карта проекта (облачная функция, бот, оплаты, хранилище, статистика) — в закрытом репозитории
Epl1r/FitHub-server, файл CLAUDE.md. Перед утверждениями про бота или сервер — читать код там.

## Этот репозиторий
- `index.html` — всё приложение одним файлом (HTML, CSS, JS). Публикуется GitHub Pages: https://epl1r.github.io/FitHub/
- `privacy.html` — политика конфиденциальности.

## Устройство index.html
- Вкладки: `tab-home`, `tab-cal`, `tab-train`, `tab-food`, `tab-profile`; нижнее меню `nav [data-tab]`.
- Данные пользователя — в localStorage (ключи `fithub_*`, например `fithub_lifts` — веса по упражнениям,
  `fithub_theme` — тема), копия — в Telegram CloudStorage.
- Сервер: константа `AI_ENDPOINT` (облачная функция Yandex). Действия: chat, digest_now, feedback, invoice, premium,
  ref, reminders, seen, stat, technique, а также фото еды без action.
- Вкладка «Тренировка» (`renderPlan`): карточка тренировки дня `#tHero` (сегодняшний день плана, в день отдыха — ближайший,
  одна кнопка старта и переключатель «С ИИ-тренером / Без камеры» — `fithub_cam`), неделя плана `#wkDays` с отметками
  (если на неделе тренировок не осталось — следующая неделя), плитки «Разбор техники» и «Программа», история.
  Готовых тренировок нет: только подобранный план (`myPlan`); без плана — одна тренировка «Всё тело» и кнопка подбора.
- Тип программы — в профиле «Мои данные» (`userData.split`: auto / fb / ul / ppl, «тяни-толкай» от 3 дней и без
  ограничений по плечам). Генератор: `SPLIT_BY`, `splitType`, `splitText`. Сохранение профиля с изменёнными условиями
  тренировок пересобирает план (`applyPlan(plan, true)` — начало 4-недельного цикла сохраняется).
- Разбор техники по видео: плитка во вкладке тренировок и блок в карточке упражнения (`tqSection`); `tqRun`
  вынимает 8 кадров (видео до 20 с), рисует позу (MediaPipe, `loadPose`), собирает коллаж и шлёт action `technique`.
  Последние 3 разбора по упражнению — в localStorage `fithub_tech`.
- Статистика: `track(событие)` → Яндекс Метрика (113832857) и action `stat` в функцию.
- Карточка «Сводка для автора» (id `ownerCard`) видна только владельцу (Telegram id 5517755450).
- Арни: чат с ИИ через action `chat`; заготовленные ответы — массив `RULES`, функция `localAnswer`.

## Как выкладывать
Правка → проверка в Playwright (эмуляция iPhone 13, тёмная и светлая тема, без ошибок в консоли) → коммит
и push в main → проверить, что https://epl1r.github.io/FitHub/ отдаёт новую версию.
